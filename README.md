## Objective

This project is a personal portfolio website that represents my professional,
academic, and personal journey. The website is designed to serve as a living
résumé that can evolve as my experience, skills, and interests change over time.

The portfolio includes an overview of my technical skills and education, my
professional experience and projects, and a more personal section about my
interests and life outside of technology.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- CSS Grid and Flexbox
- Git and GitHub

## Features

- Responsive multi-page portfolio
- Interactive orbit navigation
- Professional experience and education sections
- Featured projects with links to GitHub
- Personal photo galleries with carousel navigation
- Keyboard navigation for photo galleries
- Back-to-top navigation
- Responsive design for desktop and mobile devices

## Pages

- **Home** — A short introduction to my skills, education, career journey, and
  featured projects.
- **Experience** — A more detailed look at my professional and technical
  experience.
- **Beyond the Résumé** — A personal page about my interests, family, travel,
  hiking, and my dog Nixie.

## Build Instructions

1. Clone the repository.
2. Open the project directory.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Open `index.html` in a browser.

5. To check the code with ESLint:

   ```bash
   npm run lint
   ```

6. To format the project with Prettier:

   ```bash
   npm run format
   ```

7. To verify the formatting:

   ```bash
   npm run format:check
   ```

## GenAI Usage

Generative AI was used as a support tool during the development of this project.

## Tools

- ChatGPT — GPT-5.6
- OpenAI image generation

## How I Used GenAI

I used GenAI to:

- Brainstorm the structure and visual concept of the portfolio.
- Review and improve text used throughout the website.
- Discuss HTML, CSS, and JavaScript implementation approaches.
- Help debug JavaScript and CSS issues.
- Generate anime-style illustrations used as visual elements in the portfolio.
- Review the project against the assignment requirements.

  I used GenAI as a development and learning assistant rather than relying on it
  to build the complete project. I reviewed, tested, and modified the suggested
  code as I implemented the website.
